Picking a different type with a query typed fires a bubbling ``search-type-change`` event, so a form can search again. - ``search_types``: list of ``{display, value}`` from ``get_search_media_types``. - ``selected_type``: initially selected media type value. - ``query``: initial text. ``input_id``: id of the text input. {% endcomment %}
